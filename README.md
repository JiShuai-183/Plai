# Plai

> 面向学生的私人工具 App：**课表 · 日程 · 打卡 · 提醒 · AI 助手**，全本地存储。

Plai 是一个纯本地的个人时间管理应用。它把学生最常用的几件事放在一起：按周看课表、管理待办与每日打卡、到点收提醒，还能用 AI 对话直接查询或帮你排课排日程 —— 所有数据只存在你自己的手机上，不需要账号、不需要服务器。

## ✨ 功能

| 模块 | 能力 |
| --- | --- |
| 🗓 课表 | 学期/课程/单双周/自定义周、停课、节次时间表；周视图横向滑动切周（跟手动画）、空课天/空行自动压缩、上课状态实时变色；课表文件导入导出（JSON/CSV） |
| ✅ 日程 | 待办 / 定点日程 / 每日打卡 / 一次性跨期；优先级、按日分组、逾期置顶、完成打卡记录、日历视图 |
| 🔔 提醒 | 到点本地通知（系统调度，杀后台也能触发）、通知音跟随系统、通知渠道按「课表 / 日程」分类（可在系统设置里分别调声音与震动）、每日重复提醒、上课提前提醒、完成提示音、开机自动重排、**提醒保护**（检测系统设置并一键直达对应设置页） |
| 🤖 AI 助手 | 多供应商 OpenAI 兼容直连（Base URL 自填）；查询课表/日程并**经你确认后**写数据；会话历史、标题搜索、置顶及批量删除；跨会话发送排队、撤回编辑、独立文字/图片草稿；图片（拍照/相册/多选）识别课表；OCR 支持「对话模型视觉」与「专用服务」两种模式 |
| 🔄 自动更新 | 启动 3 秒后自动检查新版本（网络操作全有超时，失败按 +6s/+15s/+30s 退避重试）；用户确认后下载并由系统安装；SHA-256 完整性校验 + Range 断点续传；安装通道失败时可改用浏览器下载安装 |
| ⚙️ 数据 | 纯本地 SQLite；`.plai` 备份导出 / 预览合并或覆盖恢复 |

> AI 页提供会话起始页与底部新建入口；输入框上方显示排队任务，可继续输入、切换会话或撤回修改。

## 📥 下载与更新

客户端**固定**读取这个 HTTPS 清单（不可配置）：

```
https://43.142.93.106/downloads/plai/latest.json
```

- **IP 直连，不经过域名解析**：域名是否备案、DNS 是否可达都不影响更新（服务器持有 Let's Encrypt 的 IP 证书并自动续期，仍是完整 HTTPS 校验）
- 清单里给出当前版本的产物路径、字节数与 **SHA-256**；客户端下载后逐字节校验，不匹配即判定更新失败
- 服务器只保留**最新 5 个**版本目录，更旧的自动清理
- GitHub Releases 同步发布同一份 APK，可作为手动下载的备用入口：[github.com/JiShuai-183/Plai/releases](https://github.com/JiShuai-183/Plai/releases)
- 当前版本号请以清单或 `pubspec.yaml` 为准 —— 本 README 不写死版本号，避免过期

### 增量更新接入

当前开发代码支持“增量优先、全量兜底”：精确匹配上一正式版的 APK 后下载补丁，在后台合成完整安装包并校验 SHA-256，再交给系统安装。旧包不匹配、补丁下载或合成失败时自动使用完整包；安装确认和本地数据保留方式沿用原流程。

- 现有 2.4.0 客户端仍使用全量下载；下一次包含该能力的正式版本通过原有全量通道过渡，之后才可使用增量，无需用户自行卸载重装。
- 首版只提供上一正式版直达最新版的补丁，补丁须小于完整包的 80% 且至少节省 1 MiB；否则继续全量。增量只节省下载量，不缩小安装后的 App。
- 客户端未增加第三方依赖；补丁生成工具仅在构建端使用固定版本依赖。发布步骤、兼容字段和验证方法见 [增量更新发布说明](docs/增量更新发布.md)。本次实现尚未发布新线上版本。
- 验证：静态检查无问题，Flutter 全量 **917** 项测试通过；2.3.6 → 2.4.0 的真实 APK 实验生成 **5,002,463 字节**补丁，合成后与原始 **63,826,087 字节**目标包的 SHA-256 完全一致。本机 Windows JIT 合成约 5.2 秒，实际手机耗时与每次补丁大小需另行实测。

### ⚠️ 构建可被用户覆盖安装的版本

release 目前使用 **debug 签名**（`android/app/build.gradle.kts` 的 `buildTypes.release`），而 debug keystore **是按机器生成的**。所以在**新机器**上构建前，必须先把既有项目的 `debug.keystore` 放到 `~/.android/debug.keystore`，否则签出的包**已装用户装不上**（`INSTALL_FAILED_UPDATE_INCOMPATIBLE`）。

判断标准只有签名指纹，四条硬闸门（指纹 / versionCode 递增 / applicationId 不变 / 签名方案 v2）与完整发布流程见 **`docs/UPDATE_FLOW_GUIDE.md`**。

> 发布到服务器的 SSH 私钥由所有权人**线下拷贝**交付，**绝不入库、绝不上传 GitHub**（本仓库是公开仓库）。发布前**需提示开发者提供本机私钥地址**（脚本 `-IdentityFile` 只用路径、不读内容），完整步骤见 **`docs/automatic-update-release.md`**。

## 🛠 技术说明

- 架构按 feature 分模块（`lib/features/` 课表/日程/设置/AI、`lib/services/` 通知/更新/AI/音频、`lib/data/` 数据层），页面通过 Provider 依赖仓库接口，不直接写库
- 数据库：10 张表，迁移版本 `dbVersion = 6`，采用增量 `onUpgrade`（幂等容错）；新增持久发送队列及写操作执行检查点
- 路由：14 条命名路由，全部登记在 `lib/routes/route_registry.dart`
- 宽屏（≥1024px）自适应：侧栏导航 + 今日页分栏 + 课表 9–12 节自适应行高，断点统一在 `lib/shared/layout_breakpoints.dart`
- 通知遵循「无服务器本地调度」：`AlarmManager` 到点触发 + 渠道管理 + 开机恢复 + 冷启动重排

### 2.3.6（2026-11）
- **修复 AI 查询漏掉打卡任务**：每日打卡任务（如「校园跑」「每天30单词」）此前被读取工具无条件过滤，问「这个月还有什么没做的」时它们根本不在给模型的查询结果里 —— 不是模型忽略，是数据没送到。现在打卡任务会正常出现在「未完成」与「今天」的查询结果中，并标明今天是否已打卡（今天已打卡的不再算进待办）。
- **AI 回答不再出现单字噪音**：写操作完成后偶尔会多冒一条孤零零的「已」。现在写操作的结果行就是答复，不再向模型索要复述轮，单字残句会被丢弃。
- **短答兜底改为说人话**：模型查到了数据却只回「这个」「这个回报」时，不再把数据库原始 JSON 摆给用户看，改为一句提示并给出可照抄的问法；提示词也从「绝对不要只回这个/好的」这类否定式禁令改成正面要求（必须把查到的内容整理成一句话），减少「先声明再回答」诱发的半截话。
- **等待更短**：写操作（建日程、改课程、删课程）确认后不再多等一轮复述；应用状态快照按「会话 + 日期 + 消息变化」缓存，不再每句话都重建，每轮请求的上下文明显变小。
- **时间表达更贴合口语**：「今晚加一节课」「明天上午有个会」这类只指某一天的安排，不再被翻译成「整学期每周都上」——课程周次会精确落到那一天所在的周；调课时若原课程覆盖多周，默认新建一门只覆盖被调那几周的课、不移动原课程，并且动周次/删课前会先说明影响范围。
- **AI 工具合并，说明书瘦身**：13 个工具合并为 3 个（`query` / `save_task` / `save_course`），工具定义整体缩小一档，模型不必在十几个名字里挑；确认卡片在同批多笔写操作时也能各自对应正确的文案。
- **进度提示**：等待期间按「正在思考 / 正在查询 / 准备修改 / 正在执行 / 正在整理结果」分阶段说明当前在做什么，不再是干等一个转圈。
- **其它修复**：删除同名课程时在确认卡上写明还剩几门；AI 修改日程的日期/标题不再被拦截（合并工具后一度回归）。
- 质量门槛：`flutter analyze` 无问题，`flutter test` **802** 项全绿。

### 2.3.5（2026-10）
- **修复 AI 对话「连接测试正常、对话一直失败」**：真实对话是流式请求且必带工具（tools）schema，连接测试只发一条非流式短消息，所以测试只能证明鉴权与端点通。现在三种「非标准响应」都能正确处置：① 服务端在流中返回 `error` 帧（此前被整条丢弃 → 用户只看到空回复）现在直接报出服务端原因；② 网关忽略 `stream:true` 直接回整体 JSON 时按非流式解析（此前按 SSE 逐行丢弃 → 落库成「（无文本回复）」）；③ 非 JSON 错误页 / 空响应给出明确错误并附原文摘要。
- **AI 错误提示带得出线索**：400 等错误现在附带服务端原文（截断单行），并新增「模型/中转不支持 tools」「上下文超限」「额度不足」定向提示 —— 连接测试只花几个 token，通过不代表对话还有额度。
- **修复更新完成后的首次打开不弹更新公告**：公告原来只认「应用内下载安装」写下的交接记录，手动装包 / 传输工具 / 应用商店安装一律不弹（2.3.4 即如此）。现在应用内安装仍读交接记录；其它渠道则在首启用「本机上次记录版本 + Android 安装/更新时间差」判定为覆盖安装后，从线上清单取当前版本的 `notes` / `announcement` 补弹一次。全新安装不弹，同一版本只弹一次，取清单失败静默跳过。
- 质量门槛：`flutter analyze` 无问题，`flutter test` **747** 项全绿。
