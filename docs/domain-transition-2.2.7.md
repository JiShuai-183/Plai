# 2.2.7 更新域名过渡

> ⚠️ **历史文档（已失效，仅存档）**：2026-10-22 起旧域名与旧服务器通道全部下线，客户端只用新服务器 IP 直连（见 `docs/update-source.md`）。**不要照本文配置任何线上内容。**

本版本将默认更新源切换为 https://liuyangyang.online，清单路径仍为 /downloads/plai/latest.json，安装包仍使用同源相对路径、大小和 SHA-256 校验。

过渡包先发布到新服务器，再将相同字节发布到旧服务器。已安装旧版的用户从旧更新源获取本版本；安装后，下一次检查更新改用新域名，不依赖旧域名重定向。

项目所有者于 2026-10-21 选择保留上海新机、办理新域名备案并延长旧入口过渡期，原定五天后的下线计划已撤销。旧服务器和旧域名应保留至备案、公开 HTTPS 验收及客户端过渡完成，具体结束日期另行确定。未在旧入口最终下线前安装本次过渡版本的旧版用户，将无法通过旧地址自动检查更新，需要从新网站手动下载安装新版；本地课表和日程应通过覆盖安装保留，不要求卸载。

版本为 2.2.7+15。发布前需验证原签名证书、递增的 versionCode、com.plai.plai applicationId、APK v2 签名方案及通知资源。发布结果以发布验收记录为准。

发布脚本默认使用新域名和 ubuntu 用户。旧机过渡发布时显式提供旧主机和 root 用户；私钥文件路径由操作者提供，不写入源码或文档。脚本在服务器上核对 APK 与清单 SHA-256 后提升版本，拒绝覆盖已有版本目录。
