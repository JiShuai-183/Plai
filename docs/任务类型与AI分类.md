## 第3项：已实现，待真机验收

第1、2项已完成并覆盖安装调试包，随后开展本项。AI 按以下规则提出类型，仍需用户确认后写入。

| 用户意图 | 目标类型 |
| --- | --- |
| 每天都要做 | 每日打卡 `daily` |
| 一定期限内完成 | 一次性跨期 `span` |
| 没有期限，但需要做 | 待办任务 `todo`，真正无截止日期 |
| 明确时间发生的会议、考试、预约 | 定时日程 `scheduled` |

用户已确认：没有起止日期的每日事项从今天起长期有效；只有截止日期的限期事项默认从今天开始。未给期限的待办不设截止，不能擅自判为今天到期。

实现与兼容：

- `Task.dueDate` 可空；SQLite V8 无损迁移旧任务、照片与打卡记录。已有任务不重新分类、不清除原截止日。
- `.plai` 备份 V3 支持空截止，仍可导入 V1/V2；重复任务保持原有合并规则。
- 无期限待办在今日独立分组，日历不虚构到期日；长期打卡从起始日期持续显示。详情及编辑明确显示无截止或长期。
- 创建草稿在确认前固定类型与默认起始日并持久化；只修改旧任务不重新分类。
- 限期任务保留具体截止时刻；任务完成频率与提醒频率分别处理，每天提醒不代表任务每天完成。
- 无截止不安排旧版截止偏移提醒，但明确设置的每天／一次提醒仍可用；每日打卡保留每日提醒。
- 确认卡允许清除待办／打卡的截止日期，同时保留照片选择。反向区间、非法日期及非法时刻拒绝写入。
