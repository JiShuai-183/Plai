## 第3项：目标与待确认边界

第1、2项已完成并覆盖安装调试包，随后开展本项；分类行为与截止日期契约尚在开发。

| 用户意图 | 目标类型 |
| --- | --- |
| 每天都要做 | 每日打卡 `daily` |
| 一定期限内完成 | 一次性跨期 `span` |
| 没有期限，但需要做 | 待办任务 `todo`，真正无截止日期 |
| 明确时间发生的会议、考试、预约 | 定时日程 `scheduled` |

用户已确认：没有起止日期的每日事项从今天起长期有效；只有截止日期的限期事项默认从今天开始。未给期限的待办不设截止，不能擅自判为今天到期。

现有 `Task.dueDate` 必填，数据库 `due_date` 为 NOT NULL，因此“真正无期限待办”需要同步数据、列表、日历、提醒、编辑与备份能力，不能只改 AI 提示词，也不能把今天伪作截止日期。
