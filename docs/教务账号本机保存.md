# 教务账号密码：仅在本机记住

2026-09-22 用户要求新增，取代旧交接报告的“密码绝不落盘”。
Plai 仍是本地学生工具；保存用于减少手动拉取课表时的重复输入，不新增后台同步或账号服务器。

## 用户行为

- 「从教务导入课表」新增「在本机记住账号密码」，初次默认不勾选。
- 勾选本身不保存；点击「拉取课表」且成功产生预览、完成对账后才保存。
- 下次进入预填账号密码，密码默认隐藏；不会自动登录，也不会自动重试。
- 登录失败不保存、不覆盖原凭据；切换学号清空输入框里的旧密码。
- 取消勾选或点「清除已保存的账号密码」立即删除持久化记录，同时清空密码输入框。
  当前学号保留在输入框以便继续操作，下次进入不再预填。
- 存储失败明确提示，绝不明文降级，也不把成功拉取误报为失败。
- 读取/保存/清除期间禁用相关操作，避免异步读取覆盖输入、迟到保存覆盖删除。
- 既有预览、逐项选择、确认导入、HTTP 风险提示和防锁号逻辑不变。

## 代码与安全边界

- `lib/data/repositories/eams_credentials_repository.dart`：只读凭据模型、接口及安全存储实现。
- `lib/features/timetable/eams/eams_import_page.dart`：Provider 注入、记住/填充/清除交互。
- `flutter_secure_storage`：Android Keystore 保护的 RSA-OAEP + AES-GCM 加密；
  独立 namespace `plai_eams_credentials`；不开启自动错误清库，不打印底层异常。
- iOS Keychain：`unlocked_this_device`、`synchronizable: false`，仅本机解锁时读取，
  不通过 iCloud 同步/迁移到新设备。Runner 三种构建模式均配置 entitlement。
  Keychain 可能跨卸载保留，因此不要承诺卸载一定清除；请用应用内清除入口。
- 一条 `eams.credentials.v1` 加密记录保存整对凭据，密码保留原始空格/特殊字符。
- 不进 SQLite / `.plai` / 课表导出；旧版明文学号 `eams.username` 仅兼容预填，
  保存或清除时移除，备份导出和恢复均过滤该旧键。
- Android 旧版 Auto Backup 和 Android 12+ 云备份/设备迁移均排除该 namespace 的
  数据、加密密钥材料、算法配置文件；不改变课表等其它数据的备份策略。
- 本机加密不代表学校连接是 HTTPS：原教务 HTTP 限定域名例外保持不变。

## 验收

本次验证：`flutter analyze --no-pub` 无问题，`flutter test --no-pub` **571 项全绿**
（原基线 545 项）；Android Debug APK 构建成功。未发布、未使用真实账号登录验证。
首次构建曾遇到 SQLite 预编译依赖下载 TLS 握手失败，按依赖提示用系统 HTTP 客户端
访问同一 HTTPS 资源后重建成功；没有关闭证书校验或更改依赖版本。

测试覆盖仓库往返/覆盖/删除/坏记录、页面默认不保存/成功保存/重进填充/取消删除、
登录失败不覆盖、读写删除异常不泄露、异步防竞态、窄屏大字体、旧学号备份过滤。
宿主测试使用内存假实现，不访问真实教务账号，也不验证硬件 Keystore/Keychain。

新增原生插件，必须退出旧进程后重新 `flutter run`，不能仅热重载。
真机验收：勾选并拉取 → 退出应用重开 → 检查预填 → 清除 → 重开确认不再预填。
iOS 需在 macOS/Xcode 上另做构建、签名与真机 Keychain 验证。

依赖配置依据：[插件官方文档](https://pub.dev/packages/flutter_secure_storage)、
[Android Auto Backup](https://developer.android.com/identity/data/autobackup)。
