## 2. 用户已拍板的需求（**不可擅自改动**）

### 2.1 适用范围

- 生效类型：**定点日程 `scheduled` / 待办 `todo` / 一次性跨期 `span`**。
- **「每日打卡 `daily`」完全不动**：保留原「每日提醒时刻」行 + 原 Material 拨盘（`showPlaiTimePicker`）。

### 2.2 表单结构（上述三种类型）

1. **「提醒」`SwitchListTile`** — 默认关；编辑一个已有提醒的任务时开。
   - 「不提醒」的表达方式 = **关闭此开关**（用户明确选择了「改成提醒开关」，不是清除按钮）。
2. **「重复方式」`SegmentedButton<每天 | 不重复>`** — 仅提醒开启时显示。
3. **「提醒时刻」`ListTile`** — 副标题展示当前值；点击打开滚轮底部弹层。
   - 每天：**2 个滚轮**（时 / 分）
   - 不重复：**3 个滚轮**（日期 / 时 / 分）
   - 行名由「每日提醒时刻」改为「提醒时刻」（仅这三种类型）。

### 2.3 时间规则

| 项 | 用户拍板 |
|---|---|
| 日期范围（不重复） | 今天 ~ 今天 + 365 天 |
| 跨年消歧 | **必须显式标注**（如副标题「10月24日（次年） 08:00」；弹层内可显示完整年份） |
| 默认值（不重复） | 任务自身日期当天 **08:00**（scheduled/todo = `dueDate`；span = `startDate`，缺失退回 `dueDate`）；若已过去 → 顺延到「现在之后最近可选时刻」 |
| 过去时间 | **禁选**：日期下限为今天；结果 <= now 时「确定」禁用并提示「请选择晚于现在的时间」 |

### 2.4 原型阶段的行为（**当前代码就是这样，第二阶段要替换**）

- 「每天」→ 保存走现有路径，仍写 `Task.dailyRemindTime`（`HH:mm`），调度不变。
- 「不重复」→ **保存按钮禁用**，表单底部显示「「不重复」提醒将在下一步接入，暂不可保存」，代码留有 `// TODO(reminder-ui-phase2)`。
  - 目的：原型阶段绝不静默丢弃提醒或误存成每天。
- 关闭「提醒」→ 保存时不写提醒（等价原「清除」）。

### 2.5 明确暂缓

- **AI 创建日程**：用户明确「先完善手动创建，再做 AI 补全」。第二阶段**不要**顺手改 AI 工具（`lib/features/ai/ai_write_tools.dart` 的 `create_task` / `update_task`）。

## 4. 第二阶段：待实现（按依赖顺序）

### 4.1 数据模型与存储（`plai-data` + `plai-schedule` 协调）

现状：`Task.dailyRemindTime` = `'HH:mm'`（可空）；`remindOffsetMin` / `remindDate` 是**旧版单次提醒**遗留字段，新版无 UI。数据库 `app_database.dart` 当前 `dbVersion = 4`（V4 加了 `daily_remind_time`，见 `:53`、`:126-131`）。

建议方案（可调整，但必须一次说清兼容策略）：

- 新增字段：`reminder_repeat`（如 `'daily'` / `'once'`，可空 = 不提醒）与 `remind_once_at`（ISO 时间或 epoch ms，仅 once 有值）。
  - 或复用 `remindDate` 存一次性时刻 + 新增重复标志；**不要**继续把一次性提醒塞进 `dailyRemindTime`。
- DB 迁移：`dbVersion 4 → 5`，用 `_hasColumn` 的既有幂等写法补列（照 V4 的写法）。
- 兼容：
  - 旧任务（只有 `dailyRemindTime`）→ 视为「每天」；
  - 旧 `remindOffsetMin/remindDate` 任务 → 保持现有兼容调度，不要静默丢提醒；
  - `.plai` 备份导出/导入、课表/日程 JSON 导入导出、`toMap/fromMap/toJson/fromJson` 全部要覆盖（老备份无新字段 → 默认值）。
- 数据层接口文档（`数据层接口文档.md`）与 `Task.copyWith` 同步更新。

### 4.2 通知调度（`plai-notify` 拥有调度层，需协调）

现状：`lib/services/notifications/notification_scheduler.dart:124 scheduleTaskReminder`
- 有 `dailyRemindTime` → `_scheduleDailyRepeat`（`matchDateTimeComponents: time`）；
- 否则走旧 `remindOffsetMin` 单次分支（`:139`）。

需要：
- 新增「一次性」分支：`remind_once_at` 到点触发**一次**，无 `matchDateTimeComponents`；
- 完成 / 删除 → 取消（现有 `completed` 分支已取消，确认覆盖 once）；
- 已过期（`<= now`）→ 不排；启动/全量重排时（`:280`）也要覆盖；
- 本机时区语义与现有实现一致；
- 测试：一次触发、完成后取消、过期不排、重排幂等、每天/once 互斥。

### 4.3 UI 接线（`plai-schedule`）

- 移除 `:206-219` 的保存门禁与说明，保存时写入新字段（每天 → `daily`；不重复 → `once` + 时间；开关关 → 清空两者）。

- 列表/今日副标题若有提醒展示，一并处理。
- 测试：保存/回显/切换类型/清除/边界（过去时间、跨年、365 天边界）。
