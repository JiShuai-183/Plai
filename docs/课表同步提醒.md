# 课表同步提醒

2026-09-26 记录。纯应用内弹窗功能：距上次成功拉取教务处课表满 7 天（或本学期从未同步过）时，
在冷启动 / 回前台弹一次不可点外部关闭的弹窗，引导用户去「从教务导入课表」页同步。
**不做系统通知、不接 plai-notify、不后台轮询** —— App 不打开就不会提醒。

## 用户可见行为

- 触发时机：**冷启动**（壳层首帧后）与**回前台**（`resumed`）各检查一次；两处共用同一判定。
- 弹窗标题「课表同步提醒」，正文「已经 7 天没有同步教务处课表了，建议同步一下课表」。
- 两个按钮：「下次提醒」（默认按钮，`TextButton`）、「立即同步」（主按钮，`FilledButton`）。
- 弹窗**不可点外部关闭，也不可用返回键关闭**（`barrierDismissible: false` + `PopScope(canPop: false)`）——
  否则「计一次提醒」无法归档。
- 点「立即同步」→ 跳「从教务导入课表」页并带 `arguments: true`，目标页据此**自动拉取一次**
  （等价手动点「拉取课表」），**不自动导入**：仍需用户在变更清单里**逐项勾选**并点确认。
- 无已保存凭据时**不自动拉取**：只有学号无密码则把焦点落到密码输入框，学号为空则什么都不做。
- 自动拉取失败停在页面显示错误，**绝不自动重试**（沿用导入页既有硬约束）。
- 两个按钮都会先记「下一次提醒」再执行动作；跳转不等待目标页返回。

## 判定真值表（顺序即优先级）

| # | 条件 | 结果 |
| --- | --- | --- |
| 1 | `eams.sync.reminder.enabled == '0'` | 不弹。**只有 `'0'` 表示关**；缺失 / 空串 / 其它值一律视作开（与设置页同一口径） |
| 2 | 当前学期为 `null` | 不弹 |
| 3 | `lastSemesterId != 当前学期.id`（本学期从未同步）**或** `lastAt` 距今 ≥ 7 天 | 需要提醒 |
| 4 | 需要提醒但 `nextRemindAt` 存在且 `now < nextRemindAt` | 节流，不弹（也不改写 `nextRemindAt`） |
| 5 | 守卫命中：已在导入页（`route.name == eamsImport`）/ 已有对话框压栈（`route.isCurrent != true`）/ 重入（`_showing`） | 不弹，**且不写** `nextRemindAt` |
| 6 | 通过全部判定 | 弹窗；无论点哪个按钮，**先**写 `nextRemindAt = 触发时刻 + 7 天`，再执行按钮动作 |

- 间隔常量 `EamsSyncReminder.remindInterval = 7 天`。
- 时间戳损坏（非 int）按**缺失**处理，不抛错。

## 四个键（settings 表，纯字符串 KV）

键名单一来源：`lib/features/timetable/eams/eams_sync_reminder.dart` 的 `EamsSyncKeys`；设置页直接 import 取常量。

| 键 | 值 | 写入时机 | 判定用途 |
| --- | --- | --- | --- |
| `eams.sync.lastAt` | int 毫秒字符串 | 拉取成功且已有当前学期时打点 | 「距上次同步 ≥ 7 天」 |
| `eams.sync.lastSemesterId` | int 学期 id 字符串 | 同上 | 「本学期是否同步过」 |
| `eams.sync.nextRemindAt` | int 毫秒字符串 | 每次弹窗后（触发时刻 + 7 天） | 节流 |
| `eams.sync.reminder.enabled` | `'1'` / `'0'`，缺省视作开 | 设置页开关切换时 | 总开关 |

- 设置页**关闭开关时不清理**前三个键（它们由提醒逻辑自管）。关很久再开、若已超 7 天，
  下次启动 / 回前台会立刻提醒一次 —— 属节流键的正常结果，有意保留。

## 打点

- 位置：`lib/features/timetable/eams/eams_import_page.dart` 拉取流程中，`plan` 完成后调用
  `EamsSyncReminder.recordSync(semesterId)`。
- 仅在**拉取成功且已有当前学期**（`semesterId != null`）时写 `lastAt` / `lastSemesterId`；
  无当前学期时本轮不算「本学期同步」，不写。
- 写失败静默吞掉，**绝不影响已成功的拉取与预览**（与保存凭据同一精神）。

## 已知限制（诚实列出）

- App 不打开就收不到提醒：**纯应用内弹窗，不做系统通知**。
- 改系统时间可绕过：判定全基于墙钟。
- 墙钟回拨无保护：差值变负 → 不提醒；`nextRemindAt` 落在更远未来 → 最多压 7 天。
- 时间戳损坏（非法字符串）按缺失处理。
- **备份恢复会带回这四个键**：跨设备 / 跨重装恢复后最坏是多弹一次或少弹一次，**有意不处理**。
- iOS 未真机验证。
